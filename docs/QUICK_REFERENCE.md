## File Types at a Glance

| Type | Channels | Headphones | How It Works |
|------|----------|------------|--------------|
| Pure Tone | Mono | Optional | Continuous single frequency |
| Binaural | Stereo | **REQUIRED** | Different Hz per ear → listener perceives a beat |
| Isochronic | Mono | Optional | Pulsing on/off at target frequency |

## Minimum Listening Time

- **5 minutes**: the exposure used in the cited 528 Hz study
- **10-20 minutes**: a common session length for meditation or focus (practical guidance, not from a study)
- **30+ minutes**: for sleep or long work sessions (practical guidance, not from a study)

## Troubleshooting

| Problem | Solution |
|---------|----------|
| "Binaural doesn't work" | Use headphones, not speakers |
| "All files sound same" | Ensure stereo files use headphones |
| "No effect felt" | Listen 10+ min, reduce distractions |
| "Tone is harsh" | Lower volume, try with pink noise |
